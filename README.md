# Insurance in English

Upload an insurance policy PDF → pay → get a plain-English report generated by Claude.
Built with Next.js, Stripe, and the Anthropic API. Deploys free to Vercel.

The uploaded PDF stays in the browser the whole time and is only sent to your own
API route after payment — so you don't need any file-storage service to run this.

---

## The evening, in order

You need four free accounts: **GitHub**, **Vercel** (log in *with* GitHub),
**Stripe**, and **Anthropic Console**. Total cash tonight: about **$5** (a prepaid
Anthropic credit). Everything else is free / test mode.

### 1. Get your three keys

- **Anthropic** — console.anthropic.com → add a small credit under Billing →
  API Keys → create one. Copy it (starts with `sk-ant-`).
- **Stripe** — dashboard.stripe.com → flip **Test mode** ON (top right) →
  Developers → API keys. Copy the **Secret key** (`sk_test_...`) and the
  **Publishable key** (`pk_test_...`).

### 2. Push this folder to GitHub

Easiest path: install **GitHub Desktop**, drag this folder in, and publish it as a
new repository. Don't worry about `node_modules` — it's gitignored.

### 3. Deploy on Vercel

- vercel.com → **Add New → Project** → import the repo you just pushed.
- Before deploying, open **Environment Variables** and add these three
  (names must match exactly):

  | Name | Value |
  |------|-------|
  | `ANTHROPIC_API_KEY` | your `sk-ant-...` key |
  | `STRIPE_SECRET_KEY` | your `sk_test_...` key |
  | `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY` | your `pk_test_...` key |

- Click **Deploy**. A minute later you get a live URL. Open it and test with
  Stripe's test card: `4242 4242 4242 4242`, any future expiry, any CVC.

### 4. Connect your domain

Vercel → your project → **Settings → Domains** → add `insuranceinenglish.com`.
Vercel shows you DNS records; paste them into your domain registrar's DNS settings.
Live in anywhere from a few minutes to a few hours — normal.

## Adding your logo

Drop your logo file in the `public/` folder (e.g. `public/logo.png`), then in
`app/page.js` replace the `<span className="wordmark">…</span>` in the header with:

```jsx
<img src="/logo.png" alt="Insurance in English" className="logo-img" />
```

Adjust the `.logo-img` height in `app/globals.css` if needed.

## Running it on your own computer first (optional)

If you have Node.js installed:

```bash
cp .env.local.example .env.local   # then paste your keys into .env.local
npm install
npm run dev                        # open http://localhost:3000
```

## Before taking REAL money (important)

This app runs in Stripe **test mode**. Do not switch Stripe to live mode until the
business side is sorted: incorporation / trade-name registration, E&O insurance,
and a proper Terms of Service + disclaimer reviewed for an insurance-adjacent
product. The footer disclaimer in the app is a starting point, not legal cover.

To go live later: get your Stripe **live** keys (`sk_live_`, `pk_live_`) and swap
them in Vercel's environment variables.

## Tuning cost & output

- **Cheaper reports:** in `app/api/analyze/route.js`, change the model from
  `claude-sonnet-5` to `claude-haiku-4-5-20251001`.
- **Change the report format/tone:** edit `SYSTEM_PROMPT` in the same file.
- **Change the price:** `amount` in `app/api/create-payment-intent/route.js`
  (in cents) and the `PRICE_LABEL` in `app/page.js`.
